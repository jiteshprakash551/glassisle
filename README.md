# GlassIsle

A free, open-source dynamic-island overlay for Android. Dark-first, iOS-inspired glass look. Native Kotlin, zero dependencies, no INTERNET permission.

License: MIT.

Features: notification peek and expand (open source app, action buttons, inline reply), music card with transport controls and seek, built-in timer, notification-timer/call/navigation live items, charging / full / low-battery, Bluetooth and sound-mode changes, per-app filter, camera-cutout auto-align, accent colors.

Privacy: the island is hidden while the device is locked (no notification, call or music details on the lock screen). Accessibility is used only for the overlay window type and the foreground package name; no screen content is read.
